# 声迹 · 黑白线描 UI 设计方案 v1

## 视觉方向

以用户提供的 2026-10-06 截图为风格参考：纯白背景、轻松的黑色手绘线条、少量明亮颜色。以纸杯电话的声音线条连接生活记忆，用唱片、磁带、照片、柜子和信箱表达产品功能。

设计图采用内置 image_gen 分别生成。它们是可供评审的视觉设计稿；功能按键、流程、服务状态以 UI_REDESIGN_BRIEF.md 为准，图片内的文字和数量在实现时需要核对。

## 基础规范

| 项目 | 规范 |
|---|---|
| 页面底色 | #FFFFFF |
| 主要文字与线稿 | #000000 |
| 正文辅助文字 | #6B6B6B；实现时检查对比度 |
| 主交互色 | #00A8F0；蓝底黑字或按对比度加深，不能只用颜色区分选中 |
| 装饰点色 | #F5BA16；少量太阳、声音火花、纸张细节 |
| 录音与错误 | #EA4335，同时配文字或状态图标 |
| 标题字体方向 | 思源宋体 / Noto Serif SC；Logo 采用单独手写轮廓 |
| 正文与控件 | 思源黑体 / Noto Sans SC |
| 图案 | 黑色 2–3px 手绘线条，轻微不规则；图标保持可辨认 |
| 排版 | 手机390px基准，16–24px边距；桌面1440px基准，内容按任务分布 |
| 功能控件 | 触摸区域至少44px；明确焦点、选中、禁用与错误 |

## 各模块的结构

- 此刻：纸杯电话、窗边海面、一个主要录音动作，示例试听和声音地图为辅助。
- 录音：麦克风、计时和音量反馈；停止后打开选填保存表单。
- 素材库：原声先保存；示例可重复使用；只有主动点击才生成音乐日记。
- 日记选择：心情、天气、状态三组完整选项和其他输入，十个音乐方向和自由描述；完整长页面，不增加分步向导。
- 编辑：可操作的现场/音乐双轨、游标、剪裁、淡入淡出和播放工具；桌面优先承载复杂细调，手机保留各工具。
- 收藏：个人档案和收藏合并；横向滑动场景；照片挂墙、磁带与唱片放立体柜；拖动时投递箱由左向右出现。
- 聆听：沿用 Mineradio 的实际粒子与播放器，设计图中的引擎区域仅作展示；实现时复用原引擎。外层控件可用新的白底线描风格。
- 地图：真实地点的场景圆球，地图和足迹列表；不添加声音漫游、搜索或随机落点。
- 社区：连续信息流、用户照片与音频，轻分隔；全部/可聆听/图文、发布、喜欢、回应、分享、删除自己的内容。
- 账号：用户名密码登录；资料真实编辑；保留发布/删除记忆与许可入口。
- 信箱：寄出、二创授权和联系方式交换按预留状态展示，明确尚未开放。

## 动效实现建议

- 录音时蓝色声音线随输入幅度轻轻起伏；红点仅表达正在录音。
- 点击选择时用一笔蓝色线圈和勾号反馈，不重新加载整个页面。
- 收藏场景跟随手指或鼠标横向移动；物件拖动保持轮廓；箱子从左侧进入承接位置。
- 保存成功让磁带或唱片轻微回弹，保留下一步的主动操作。
- 支持减少动态效果；粒子与原播放器复用已有实现。

## 功能核对原则

按钮和表单以 docs/UI_REDESIGN_BRIEF.md 的逐项清单为交付依据。设计图不等于可点击原型；地图位置、音频信息、日期和用户内容为示例。高级AI、语音识别启用和真实信件投递不可因设计图看起来可用而标为已经上线。

功能状态板补充空态、上传中、保存失败、定位天气失败、地图失败和AI条件状态。权限错误页的“重试录音”是建议保留的恢复入口，实现时需要与权限重试逻辑一起接入。
