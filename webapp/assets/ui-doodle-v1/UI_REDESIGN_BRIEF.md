# 声迹 SoundTrace：全站 UI 重设计说明与资产清单

整理日期：2026-10-06。依据当前正式版本代码核对，包含页面、子界面、弹窗、功能按键、输入项、手势和条件状态。

用途：把本文件的“产品定义 + 全局要求 + 对应页面章节”交给 UI 生成工具。更换视觉语言时，保留各页面的功能和流程关系。这里的“子界面”可以继续采用弹窗、抽屉或页面内切换，不必新增路由。

## 1. 产品定义与不可丢失的流程

声迹是一款用声音记录生活、把原声制作成音乐日记、以唱片/磁带/照片收藏回忆，并通过地图和社区回看与分享的产品。

- 磁带：保存录制的现场原声。
- 唱片：保存编辑后的音乐，以及该次记忆的笔记、图片、时间、天气、心情、状态和地点。
- 照片：展示用户上传的照片/胶片相片，与同一条记忆关联。
- 信箱：表达人与人交换声音记忆的设想；正式版本的真实投递与匹配尚未接入。
- 用户上传图片或视频时，用其表现记忆背景；没有上传时，保留白底黑字的文字呈现。

主创作路径：

**此刻 → 录音 → 原声保存表单 → 声音素材库 → 用户点击“生成音乐日记” → 选择心情/天气/状态 → 选择音乐方向/自由描述 → 音乐编辑 → 保存音乐日记 → 我的收藏/声音地图；可自行发布到社区。**

录音结束后不能自动跳到音乐编辑，也不能自动生成音乐。保存原声和制作音乐是两个明确的动作。更新音乐时保留同一条记忆，原声、图片和坐标不应丢失或重复创建。

## 2. 全局视觉与交互要求

### 2.1 当前视觉基线

- 主体为纯白底，提醒色/主要交互色为天蓝，文字为深蓝灰。
- 场景和物件延续温暖手绘插画、可见笔触、自然光、柔和色彩的记忆感。
- 内容以场景、物件、声音和用户的照片为主；减少卡片外框、装饰性文本框、长解释。
- 主按钮要明确，次要操作可以用图标或轻量文字。图标仍需要可理解的名称。
- 新风格可以调整字体、色彩、材质与排版；功能清单、流程关系、状态反馈保持完整。
- 手机优先：以 390 × 844 为主要设计画布，兼顾 320px 宽；桌面建议 1440 × 1000。
- 不把按钮文字、计时器、进度条、输入框、导航或选中勾号画进背景图。它们必须能独立交互。

### 2.2 全局入口

| 控件 | 功能与出现条件 |
|---|---|
| 声迹 Logo/品牌 | 返回此刻首页 |
| 此刻 | 主导航，进入 `/` |
| 声音地图 | 主导航，进入 `/map` |
| 社区 | 主导航，进入 `/community` |
| 我的 | 主导航，进入 `/album`；个人资料与收藏已合并 |
| 登录/账号昵称 | 访客打开登录弹窗；已登录打开账号管理 |
| 我的收藏 | 工作台页的收藏入口；手机窄屏当前收起该顶部入口，可通过其他入口访问 |
| 声音地图 ↗ | 工作台页脚地图入口 |

当前此刻、录音、地图、社区、收藏使用四项主导航；React 声音工作台主要使用品牌、账号、收藏入口和页脚链接。生成新 UI 时可以统一导航，但不要丢失工作台保存操作或让导航占据编辑区。

### 2.3 必须覆盖的通用状态

访客/已登录；首次空白/已有内容；选中/未选中；按钮可用/禁用；读取中；上传中；保存成功/失败；音频无法解码；麦克风拒绝/无设备/浏览器限制；定位拒绝/天气未获取；AI 未连接/生成中/失败；删除确认；无网络/重试。

所有弹窗保留关闭或取消路径。保存中避免重复提交；错误时原声仍能保留。用户未登录时保存应打开登录窗口，登录成功继续原来的操作。

## 3. 页面总览

| 路由 | 主页面 | 同一页面中的关键子界面 |
|---|---|---|
| `/` | 此刻首页 | 场景、录音入口、示例试听入口 |
| `/capture` | 快速录音 | 录音中、原声保存表单、保存成功 |
| `/studio` | 声音手记 | 录音/导入、示例音频、声音素材库、日记选择页、音轨编辑、保存表单 |
| `/album` | 我的收藏间 | 个人档案、横向场景、物件详情、个人资料编辑、沉浸聆听、信箱 |
| `/map` | 声音地图 | 地标弹窗、我的足迹列表、播放器 |
| `/community` | 社区 | 分类信息流、发布区、回应区 |
| 全站 | 账号弹窗 | 登录、注册、账号管理、修改密码、删除确认 |

`/me` 当前跳转到 `/album?profile=1`，不再设计为独立个人主页。旧版 `me.html`、旧收藏页和素材预览 HTML 不作为新的产品页面。

## 4. 此刻首页 `/`

### 页面目的与布局

用一幅有生活气息的场景邀请用户记录或聆听。顶部为品牌和账号；主体是大场景插画与一句简短标题；录音按钮为核心动作；示例试听和声音地图为辅助入口；底部四项主导航。

### 功能按键与手势

| 控件/手势 | 功能 |
|---|---|
| 录一段声音 | 进入快速录音页 |
| 海港午后 / 试听示例 | 打开收藏页中的沉浸聆听，播放示例声音 |
| 声音地图 | 进入地图 |
| 双指缩放/捏合 | 手机首页进入声音地图；按钮入口仍保留 |
| 品牌、账号、四项主导航 | 全局入口 |

设计时保留场景沉浸感和一个突出的录音动作，不增加多层欢迎页或功能介绍卡。

## 5. 快速录音页 `/capture`

### 5.1 待录音/录音中

中心为麦克风主按钮，上方计时，下方显示简短状态；录音后可试听原声。可以使用一幅安静场景作为点缀，但录音按钮必须独立。

| 控件 | 功能 |
|---|---|
| 点击录音 | 请求麦克风并开始录制 |
| 结束并保存 | 同一个主按钮的录音中状态；结束录音并弹出原声保存表单 |
| 原声播放器 | 播放/暂停、拖动进度；浏览器支持时调节音量 |
| 或者导入已有音频 | 权限错误时出现，进入工作台导入音频 |
| 计时、权限/录制状态 | 不是按钮，但不可从设计中遗漏 |

### 5.2 原声保存表单

自动弹出“这是什么声音？”表单，允许只填部分或直接跳过。这里是给原声命名和补充记忆，不是音乐制作前的必选页。

| 控件/输入项 | 功能 |
|---|---|
| 回答/声音名字输入 | 为录音命名 |
| 说话 / 说给我听 | 录制一小段描述并做语音转文字；识别未启用时显示真实错误，仍可文字填写 |
| 此刻心情标签 | 可选：宁静、思念、雀跃、忧郁、治愈、冒险；当前快速保存标签与音乐日记选择页是两组不同用途的标签 |
| 地点输入 | 手动填写录音地点 |
| 补充笔记 | 多行文字输入 |
| 选择照片/图片 | 支持多张图片；显示缩略预览；正式保存最多 6 张 |
| 选择视频 | 正式保存最多 2 段 |
| 选择补充音频 | 正式保存最多 4 段 |
| 时间、天气、坐标显示 | 获取成功显示结果，失败显示未获取；时间保留 |
| 同时分享到社区 | 勾选后在保存时发布 |
| 跳过直接保存 | 以最少信息保存原声 |
| 保存这段记忆 | 保存填写内容和原声 |

快速录音页面当前在打开表单时尝试定位和天气；工作台保存弹窗另有“获取位置与天气”按钮。新 UI 应允许手动输入，并清楚表现获取失败。

### 5.3 原声保存成功

展示原声磁带封面、标题和保存结果；不得自动跳转到编辑。

必须保留：**生成音乐日记、去收藏间看看、再录一段、回首页**。

## 6. 声音手记：录音与素材库 `/studio`

### 6.1 首次进入

顶部品牌/账号、简短标题；“我的示例音频”位于易于发现的位置；下方是录音/导入入口及素材库。已有原声时，突出当前素材，而不是重复展示大录音场景。

| 控件 | 功能与条件 |
|---|---|
| 开始录音 / 结束录音 | 录制原声；结束时打开保存表单，不生成配乐 |
| 导入音频 | 选择本地文件，解码后进入原声准备状态 |
| 先听一个示例 | 导入现有溪边示例；不自动生成音乐 |
| 继续上次的手记 | 有设备草稿时出现，恢复音轨编辑草稿 |
| 新建手记 | 清空当前工作台项目，回到初始状态；不删除账号中已保存的原声或示例 |
| 录音计时与音量条 | 录音中显示 |

### 6.2 我的示例音频

一条简洁音频栏，包含名称、时长、保存状态。示例保存在账号中，仅自己可见；不是社区动态，也不会仅因上传就成为收藏唱片。

| 控件 | 功能与条件 |
|---|---|
| 上传示例音频 | 没有示例时的主动作，上传并保存到账号 |
| 试听播放器 | 已有示例时出现：播放/暂停、进度、音量（浏览器支持时） |
| 使用此音频 | 把保存的示例作为本次原声；无需重新选择文件 |
| 替换 | 用新的音频替换账号示例 |
| 删除 | 删除保存的示例，不删除由它另外制作的记忆 |
| 重试 | 读取失败时出现 |

支持浏览器可解码的音频；导入文件小于 50MB，时长 0.25 秒到 2 分钟；实际播放原声与编辑播放互斥。

### 6.3 声音素材库

当前素材为主要区域：声音标识、标题、时长、是否保存、试听播放器、主动作。下方已有素材列表，每项含磁带封面、标题、录制日期、时长。

| 控件 | 功能 |
|---|---|
| 当前原声播放器 | 试听原声，不添加音乐 |
| 保存素材 | 原声尚未保存时出现，打开保存表单 |
| 生成音乐日记 | 由用户主动进入日记选择页；原声尚未保存时先保存，再进入 |
| 已保存素材条目 | 点击选择已有原声并载入当前素材区 |
| 重试 | 素材读取失败时出现 |

空态应有录音/导入入口。不要把“查看原声”“选择原声”和“生成音乐日记”误合并成一次自动跳转。

工作台原声保存弹窗成功后还保留：**生成音乐日记、留在素材库、打开我的收藏、下载原声、关闭**。

## 7. 音乐日记选择页 `/studio` 的选择状态

### 页面目的与布局

以“这一刻，是什么样的？”开场。按照心情、天气、状态排列三组插画选项；每组独立单选；选择“其他”后展开输入框。其后为音乐方向和自由描述，最后是开始制作主按钮。

手机目前三列插画，桌面可增加列数；也可改成有足够可见提示的横向选择，但三组不能被隐蔽地藏进设置。

### 7.1 全部选择控件

| 分类 | 选项 |
|---|---|
| 心情 | 平静、开心、兴奋、思念、低落、疲惫、期待、怀念、其他 |
| 天气 | 晴天、多云、下雨、下雪、有雾、有风、夜晚、其他 |
| 状态 | 工作、学习、散步、徒步、约会、旅行、通勤、独处、运动、聚会、其他 |
| 音乐方向 | 空灵氛围、Lo-fi、电影感、轻钢琴、木吉他、轻爵士、电子、管弦、轻摇滚、世界音乐 |

天气组中的“夜晚”是当前选项；若后续调整为天气/时段独立分类，需要同步产品和代码，不能只在生成图中悄悄改变。

### 7.2 必须保留的按键与输入

- **← 素材库**：返回素材选择。
- 每个选项可点击，选中时有明确视觉状态和勾号。
- **其他心情、其他天气、其他状态**：选择“其他”后出现，文字填写。
- 十个音乐方向标签：选择创作方向。
- **自由描述**：可选多行输入，例如“温暖的钢琴和轻鼓点，像傍晚一起走回家”。
- **开始制作音乐日记 →**：三组选择完整后进入音乐编辑；未填完整显示对应提醒。

此处三组是进入音乐制作的必选项，和原声保存表单的选填规则不同。自由描述不是给音乐风格增加第十一个固定限制，而是保留开放表达入口。

## 8. 音乐编辑页 `/studio` 的编辑状态

### 页面目的与布局

顶部显示心情/天气/状态摘要和修改入口；唱片预览、声音标题、草稿状态、保存按钮；中部是播放工具和现场/音乐双音轨；下方是音乐方向、混合比例、重新录音/更换音频和细调。高级 AI 操作在可用时展示。

### 8.1 常驻功能

| 控件 | 功能 |
|---|---|
| 修改此刻 | 返回心情/天气/状态及音乐方向选择 |
| 收藏这段声音 | 打开音乐日记保存弹窗 |
| 播放 / 暂停 | 试听当前混音 |
| 回到开头 | 将播放位置归零 |
| 撤销编辑 | 回退可撤销的音轨修改 |
| 重做编辑 | 恢复被撤销的修改 |
| 缩小时间线 / 放大时间线 | 改变波形时间轴的显示比例 |
| 播放位置滑块 | 拖动定位播放位置 |
| 每轨静音 / 取消静音 | 分别控制现场、音乐及其他声源轨 |
| 音乐方向选择器 | 在十种方向中切换本地编配 |
| 现场 ↔ 音乐平衡滑块 | 调整原声与音乐的混合比例 |
| 重新录音 / 结束录音 | 录制新的原声；结束仍先进入原声保存流程 |
| 更换音频 | 导入新的原声，返回素材准备流程 |
| 细调 + / − | 展开或收起高级编辑区 |
| 新建手记 | 重置当前项目 |
| 关闭错误提示 × | 清除当前提示，不删除音频 |

波形不是装饰图片：需要保留片段拖动、起止裁剪、淡入/淡出调整、播放游标和时间刻度。不可生成一张静态波形替代这些操作。

### 8.2 细调区

| 控件 | 功能 |
|---|---|
| 片段选择器 | 选择要调整的轨道片段 |
| 出现位置数值 | 调整片段在时间线上的位置，单位秒 |
| 原声起点数值 | 设置所使用原音频的起点 |
| 原声终点数值 | 设置所使用原音频的终点 |

### 8.3 AI 条件操作

| 控件 | 条件与功能 |
|---|---|
| 生成专属旋律 / 再创作一版 | AI 连接后可用；未连接时显示不可用状态 |
| A 草稿 / B 专属旋律 | 生成过 AI 版本后出现，切换试听版本 |
| 停止等待 | 生成任务处理中出现，停止等待并保留已有音频 |
| 辨认录音中的声音 | AI 可用且展开细调时，分析声源 |
| 识别结果标签 | 点击将其作为目标声源 |
| 想留下的声源输入 | 手动描述鸟鸣、雨声等 |
| 提取声音 | 提取指定声源 |
| 这是我的哼唱 | 对哼唱进行处理 |

高级 AI 服务当前未接入正式版本。生成稿应画出可用/不可用/处理中状态，不把按钮画成必然成功。

## 9. 音乐日记保存弹窗

### 布局

桌面可用左封面右表单；手机为纵向内容。标题和笔记为主，地点和媒体为辅助；成功状态展示保存结果。复用原素材时沿用已有照片、视频和原声。

### 功能控件

**关闭、声音名字输入、说给我听、获取位置与天气、地点输入、心情标签、补充笔记、照片上传、视频上传、补充音频上传、六个收藏场景选择、同时分享到社区、跳过直接保存、保存这段记忆。**

- 图片/视频/补充音频上传在创建新记忆时出现；音乐更新已有记忆时沿用原素材，当前不再次展示上传项。
- 已有素材照片需有“沿用 N 张照片”的状态说明，避免误以为丢失。
- 保存时保留此前选择的心情、天气、状态、音乐方向和自由描述。
- 成功后保留 **打开我的收藏、下载原声、关闭**。
- 当前成功页的下载按钮下载的是原声；不能在新 UI 中标成“下载生成音乐”而不修改实现。

原声保存的六个心情标签与日记选择的八个心情目前并存。重设计时可统一其视觉，未来若统一词表，需要同步实际逻辑。

## 10. 我的收藏间 `/album`

### 页面目的与布局

个人主页与收藏合并。顶部是个人档案条，包含头像、昵称、签到信息；主体是一组左右滑动的场景。场景里照片挂在背景板/照片墙，唱片和磁带放在有立体效果的柜子上，信箱作为互动意象。

高级 AI 音乐、AI 笔记/封面生成、语音识别服务启用、真实信件投递/匹配、联系方式交换、自动找回密码等仍需相应服务或后续实现。当前笔记主要由用户填写；自由音乐描述已保存，不能称为已经被生音乐模型理解。公网部署仍需云服务器、域名与备案条件。不要用生成的 UI 画面暗示这些服务已经上线。

源码核对范围：`soundtrace_public.py` 的路由；`webapp/home.html`、`capture.html`、`album-room.html`、`map.html`、`community.html`；`studio/src/` 的 App、SampleAudio、SoundLibrary、DiarySetup、Editor、SaveDialog；全局导航/账号和收藏/社区脚本；Mineradio 集成样式与原播放器控制区。
