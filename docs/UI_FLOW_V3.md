# 声迹 UI 与音乐日记流程 · 2026-10-07

## 本次实现

- 地图独立重做：直接使用由第 23 / 24 张设计稿提取的手机 / 桌面背景，桌面右侧足迹，手机下方横向足迹；照片地标、手绘边框详情、播放、进度、关闭、缩放、拖动均为真实控件。
- 没有真实足迹时显示明确标注的西湖示例；有真实坐标时使用地理底图和同套控件按实际坐标展示。手绘西湖背景属于示意，不用于虚构其他城市的位置。
- 不带坐标的记忆进入足迹列表和未定位区，不绘制虚假地理地标。原声、音乐、照片、笔记、时间和适用的视频均可查看。
- 社区追加三条明确标注的示例，照片和手绘装饰直接裁切自已批准的第 25 张设计稿；真实动态继续使用账号、服务器存储、喜欢、回应与删除接口。
- 收藏照片缩小、轻微旋转，统一裁切并增加不规则纸框。桌面和手机分别保留聆听按钮原有定位，不再被悬停位移覆盖。
- 音乐日记逐屏选择：天气 → 心情 → 状态 → 图片 / 自己的话 / 自选定位 → 音乐风格 → 微调。返回保留选择和图片；普通选项点击后自动进入下一屏，其他输入需填写后继续。
- 选择音乐风格后直接进入编辑。完成保存后进入我的收藏，弹出同步社区、寄信、查看收藏和声音地图入口。
- 音乐保存更新原有记忆，不新建重复条目；支持追加照片并更新封面；取消记录位置会清除旧坐标。
- 一键同步社区分享唱片音乐及全部记忆照片。再次同步更新同一动态，保留原动态标识及互动。
- 远方信箱已经接入数据库队列：只匹配主动选择接收来信的账号；未匹配显示等待，匹配后接收方可查看音频 / 图片 / 文字；不会把精确坐标随信件发送。重复寄送同一物件不新增重复信件。
- Mineradio 原版播放器和粒子引擎文件未改动。

## 验证

- 生产构建成功。
- 15 项独立临时数据库测试通过，覆盖多账号隔离、媒体权限、追加照片、定位取消、音乐更新、社区同步更新、队列匹配、寄信幂等、删除和重启。
- 浏览器完整流程通过：示例上传 / 登录 / 复用 → 顺序选择（含其他）→ 图片与笔记 → 微调 → 保存 → 我的 → 同步社区 / 等待寄信 → 地图。
- 模拟麦克风录音保存、账号注册、收藏、地图、真实社区喜欢和回应流程通过。模拟麦克风不代表用户机器的实际录音权限。
- 桌面 1440、手机 390 / 320 的页面没有横向溢出，浏览器没有脚本错误。
