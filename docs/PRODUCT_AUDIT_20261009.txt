声迹 SoundTrace 全产品验收 — 2026-10-09

结论
当前产品已能完成“导入原声 → 填写情境 → Mureka 生成音乐 → 混音编辑 → 收藏 → 社区分享 / 匿名交换”的真实闭环，但尚未完整实现“地点是乐器，记忆是旋律”的最初设想。尤其不能把文字生成配乐加原声混音，等同于环境声乐器化或哼唱驱动音乐模型。

验收依据与范围
对照 docs/NORTH_STAR.md 与后续 UI_FLOW_V3 流程，并以本次当前公开站点实际表现为准；旧文档中实验服务“已上线”的描述不代表当前公共部署可用。
本地独立测试服务 http://127.0.0.1:8096，数据在 runtime/full-audit/data，与原有用户数据隔离。使用两个专用测试账号、合成八秒四音旋律、合成图片和虚拟北京坐标。没有把用户真实录音、照片或精确位置发送给模型。
浏览器实际操作覆盖主要入口与下述闭环，辅以接口、权限和导出文件检查。尚未验收真机麦克风、真实人声质量、小程序端、正式公网 HTTPS 和 Docker 实际启动；不能据本地通过宣称已公开上线。

已跑通的流程
1. 账号登录、音频导入、原声保存；原声与生成音乐分别保留。
2. 天气、心情（含自定义）、活动、故事和音乐方向填写；前后切换保留已填内容。
3. Mureka 正式接口真实生成一次，完成异步查询、WAV 下载和独立音轨加载。失败时保留原声，修复网络后重试成功。
4. 播放暂停、播放时间推进、现场声 / 音乐比例、精确裁剪、撤销重做、草稿恢复、保存混音。
5. 最终时间线裁至 45 秒，实际保存 WAV 为 45.1 秒（含输出尾音）、44100 Hz、双声道，音频非静音。已同步最终结果到本地测试社区。
6. 收藏间展示照片 / 原声磁带 / 音乐唱片，沉浸播放器加载及队列播放；签到和寄出计数显示。
7. 社区分享、点赞和文字回应实际保存并显示；窄屏操作行已修复溢出。
8. 双账号匿名交换：双方明确选择接收后配对，收信箱显示对方作品和使用授权。来信接口未暴露经纬度；访客不能读取私有原声，共享混音可以读取。
9. 腾讯地图配置鉴权、坐标转换、记忆标记、列表与详情。最初底图连接失败，最终重新加载后真实道路底图与标记均已显示；无位置记忆保留在列表。失败状态有说明和重试。
10. 图片上传和原图保留通过；真实 Seedream 生图请求失败，未当作成功验收。
11. 本地 Basic Pitch 从八秒合成旋律完成识别并新增“哼唱旋律”音轨，播放启动成功。这是本机旋律提取链路验证，不代表真实人声准确率达标，也不等于哼唱驱动 Mureka。

本次已修复
P0：服务端 httpx 继承本机 Windows 代理导致外部服务连接失败。新增每应用代理开关 SOUNDTRACE_HTTP_TRUST_ENV；本地私有配置使用 false 后 Mureka 正式生成成功。默认 true 不改变其他部署的既有代理行为，不修改系统代理。
P0：解码与导出音频上下文取样率不一致，45 秒作品实际输出约 41.44 秒。统一播放库自身上下文与解码取样率，再次导出实测 45.1 秒。
P1：裁剪详情按错误取样率显示时间，8 秒素材曾显示约 7.3 秒；改为使用片段自身取样率。
P1：单次精确裁剪后撤销按钮不能立即启用；移除不必要的事务包装，实际验证裁剪、撤销、重做。
P1：/studio 空状态没有恢复草稿入口；已补齐并验证恢复音轨和元数据。
P1：外部接口错误信息过于笼统；现在区分 HTTP 状态、网络代理和超时，避免泄漏上游 URL、响应正文及凭据。
P1：语音转文字服务未启用时仍显示可点击按钮；现在依据服务能力禁用并提示直接输入。
P1：收藏页提前加载完整第三方播放器，并请求未接入的外部账号接口；改为进入聆听时加载，嵌入模式使用本地账号 / 封面适配，隐藏无对应功能的控件。
P2：320 像素窄屏社区按钮横向溢出；允许换行，实测页面宽度不超出视口。
P2：占位唱片容易被误认为真实作品；明确标为占位。寄出成功立即更新计数。
P2：腾讯底图空白没有解释；新增连接提示、重试和可继续使用的足迹列表。
部署一致性：新增网络模块加入 Docker COPY 与部署源码归档白名单，避免本地成功、容器缺少模块。

仍存在的问题及下一步
P0 / 核心愿景缺口：当前未配置声音分析 / 分离服务。辨认与提取按钮明确禁用，无法实际把环境声分离成可用素材。需要部署并连接声音处理服务，再用真实环境录音验收，不是单填音乐 API Key 就能完成。
P0 / 核心愿景缺口：Mureka 当前集成使用文字情境生成；没有向模型传入原声 / 哼唱作为旋律条件。环境声转鼓点、节拍对齐、段落结构和“保留哼唱 ↔ 自由发挥”控制尚未形成当前产品闭环。
P1 / 生图阻断：方舟 Key 认证请求成功，但默认 doubao-seedream-5-0-pro-260628 图片生成返回 HTTP 404。模型列表出现该名称并不证明该账号可生成；需要核对实际模型 / 接入点和权限。未确认具体上游错误代码，不能断言唯一原因。原照片不会因失败而丢失。
P1 / 音乐时长：本次提示词要求 30–60 秒，服务返回约 3 分 17 秒。当前可手动裁剪到目标时长，但不保证自然的 30–60 秒结构和收尾；需要后续接口参数能力确认或音乐结构处理。
P1 / 网络稳定性：本机曾出现腾讯瓦片连接关闭；最终实拍已显示真实底图，但不能据单次恢复证明所有网络稳定。服务端代理开关不控制浏览器网络；正式域名、访问限制与手机网络需要部署后复验。
P1 / 真机质量：合成旋律验证了处理链路与文件完整性，不能替代真实哼唱准确率、环境噪声识别、音乐审美及图片风格验收。物理录音、权限拒绝与移动端后台恢复待真机测试。
P2 / 扩展设想：城市公共声音发现、路线连播专辑、联系方式交换、授权后二次创作与衍生树尚未完整实现。它们属于后续功能，不能用当前个人地图和授权勾选框代替。
