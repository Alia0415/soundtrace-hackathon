# 设计参考网站大全（音乐/唱片/磁带/照片墙/编辑器）

## 2026-10-03 精选：声迹下一轮 App UI 方向

这些是完整作品或真实产品，优先研究交互方式、信息密度和视觉重心；图片版权仍归各作者。

| 参考 | 声迹可以借鉴的部分 |
| --- | --- |
| [Rotational Music App](https://www.behance.net/gallery/62169521/Rotational-Music-App-2017) | 上下选唱片、左右选曲目，颜色和实时音频联动；适合收藏间的滑动与聆听衔接 |
| [Sonar](https://www.behance.net/gallery/243849175/Sonar-App-Design) | 地图、滑动发现与少文字引导；适合声音地图和社区探索 |
| [TurnPlay](https://www.behance.net/gallery/6291091/TurnPlay-vinyl-player-for-iPad) | 把真实唱机动作转成触摸交互；适合唱片藏品的拿起、放下和播放 |
| [Rewind Music Player](https://www.behance.net/gallery/83183449/Rewind-Music-Player) | 黑胶与磁带作为主视觉，同时保持播放器简洁 |
| [Artifact](https://dribbble.com/shots/27682571-Artifact-Memories-Told-Through-Objects-Mobile-App-UI-UX-Design) | 以物件承载个人故事；适合照片、磁带、唱片的记忆详情 |
| [Colliq](https://www.behance.net/gallery/244071195/Colliq-The-first-app-for-audiophiles) | 从实体唱片到数字收藏的完整 App 和设计系统 |
| [Vinyl Music Player](https://dribbble.com/shots/14611479-Vinyl-Music-Player-App-UI-Concept) | 3D 黑胶翻转和有机手感的动效 |
| [Cassette Music Player](https://dribbble.com/shots/16062720-Cassette-Music-Player-App-Ui-design) | 磁带作为播放器的视觉主体 |
| [Rewind: record, share and listen to memories](https://www.behance.net/gallery/87192393/Rewind-Mobile-APP-UXUI-Design) | 记录、分享与重听记忆的产品路径 |
| [Radiooooo](https://app.radiooooo.com/) | 地图和年代成为探索音乐的直接入口 |
| [Radio Garden](https://radio.garden/) | 拖动地球听当地电台的空间式交互 |
| [NTS Radio](https://apps.apple.com/us/app/nts-radio/id1204567739) | 真实产品的编辑感内容与常驻收听入口 |

当前最值得先看的三项：Rotational Music App 的滑动和声画联动、Sonar 的少文字探索、Artifact 的物件记忆叙事。声迹既有的绘画场景和 Mineradio 粒子可以承接这些交互，不必改变画风。

## 7. AI 提示词网站（生成设计图用，2026-09 验证活跃）

### 图像提示词搜索库（看图→抄词）

- **Lexica** — Stable Diffusion 图片+提示词搜索引擎
- **Civitai** — 模型+作品+完整 prompts（含参数）
- **OpenArt / PromptBase / Snack Prompt** — 提示词社区/市场
- 入口盘点：[2026 十大提示词库横评](https://sureprompts.com/blog/best-ai-prompt-libraries-2026)、
