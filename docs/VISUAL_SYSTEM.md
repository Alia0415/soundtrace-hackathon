# 声迹 SoundTrace · 视觉规范 v1

## 方向

以用户提供的“记忆柜”插画为画风参考：明亮、温暖的手绘厚涂，海蓝与奶油白为主色，午后斜阳照在有时间感的收藏物上。产品世界是一间可以收藏、聆听、寄出记忆的小屋。视觉要让故事和声音成为主角，不把每个界面画成满屏插画。

关键词：**阳光、海风、手作、收藏、来信**。避免：深色霓虹、冰冷科技面板、塑料感 3D、过度磨皮的写实照片、大量竞争注意力的纹理。

聆听状态新增独立的暗场舞台：用户进入“沉浸聆听”后，借鉴 Mineradio 的聚焦播放与音乐响应，降低周围亮度、突出当前记忆物件与故事。暗场只用于播放，不覆盖收藏间的日光手绘主场景；详见 [MINERADIO_ADAPTATION.md](MINERADIO_ADAPTATION.md)。

## 设计令牌

| 用途 | 色值 | 使用方式 |
| --- | --- | --- |
| 深海蓝 `--ink` | `#174E68` | 主文字、主要操作、导航 |
| 海湾蓝 `--sea` | `#2789B6` | 可点击元素、音频进度、地图轨迹 |
| 天光蓝 `--sky` | `#82C6E9` | 高光与轻量装饰 |
| 奶油纸 `--paper` | `#FFF8E9` | 页面底色、卡片、信纸 |
| 暖白 `--white` | `#FFFEF8` | 文字承载面 |
| 日光金 `--sun` | `#E5AD52` | 少量焦点、图钉、邮戳 |
| 叶绿 `--leaf` | `#718F69` | 场景陪衬，不作主要操作色 |
| 次级文字 `--muted` | `#567486` | 时间、地点、说明 |

主文字在浅色承载面上使用深海蓝。插画可以有厚涂肌理，功能区、正文、表单保持干净。背景纹理透明度建议低于 8%，勿压住照片与故事。

## 字体与排版

- 标题：优先系统可用的中文宋体/衬线字体（`Songti SC`, `STSong`, `SimSun`），体现记忆册气质；正文使用 `PingFang SC`, `Microsoft YaHei`, `Noto Sans CJK SC` 等清晰无衬线字体。
- 页面主标题 32–40 px，卡片标题 18–22 px，正文 14–16 px，辅助说明不小于 12 px。
- 标题不嵌入插画。用户的作品名、地点和时间均由网页文字渲染，支持换行与无障碍读取。
- 留白优先：8 px 基础间距；卡片常用 16/24/32 px 内边距；圆角 16–24 px，按钮圆角可更大。

## 材质与光照

- 同一套物件都从左上方受暖日光照亮，右下方留柔和冷影。
- 纸：微黄、略有纤维与不规则边缘；蓝漆：能看到笔触和局部磨损；金属：少量黄铜高光；玻璃/透明塑料：青绿透光。
- 默认不在物件 PNG 里烘焙大片场景阴影，由组件在页面上统一添加轻阴影；不要叠加第二层厚重投影。

## 四种记忆载体

| 载体 | 信息含义 | 视觉规则 | 关键状态 |
| --- | --- | --- | --- |
| 照片 | 一次经历，关联现场录音与故事 | 奶油白相纸、蓝色图钉；照片内容可以由用户图替换，标题放在相纸下沿或卡片外 | 默认、翻开故事、选中待寄 |
| 磁带 | 未整理或提取出的原始声音素材 | 奶油壳体、蓝色面板、双卷轴；纸质标签承载声源名与时长 | 默认、试听、拖动、已授权/未授权 |
| 唱片 | 完成的音乐作品 | 方形画套露出蓝色唱片；封面可随地点/心情替换 | 默认、播放中轻转、收藏、待寄 |
| 信箱 | 匿名交换入口 | 蓝色旧漆、奶油门板、黄铜投递口；寄信动作有明确信息回执 | 空、拖入高亮、投递中、已寄出、收到新信 |

这组 PNG 是**首版画风样本和默认插画**，不是把所有用户内容画成同一张海边图。实际产品应保留相同物件外框，并将用户照片、唱片封面、磁带标签和文字作为独立可替换图层。

## 交互约定

1. 可点击物件悬停时抬起 2–4 px；键盘聚焦有清晰描边。触屏仍提供“寄出”按钮，不能只靠拖拽。
2. 唱片播放中仅唱片轻转，画套不转；磁带播放时两卷轴缓慢转动。
3. 拖到信箱上方时，信箱放大约 3%，投递口亮起；寄出后出现简短回执，明确说明当前是否真的投递给其他用户。
4. 尊重 `prefers-reduced-motion`，减少动态效果时取消旋转和位移动画。
5. 四种物件在手机端最小展示宽度约 140 px，重要状态不能只靠颜色区分。

## 首批文件

位于 `webapp/assets/visual-v1/`：`vinyl.png`、`cassette.png`、`photo.png`、`mailbox.png`。均为透明背景 PNG。预览页面：`webapp/visual-preview.html`。

场景背景另见 `docs/SCENE_ASSETS.md` 和 `webapp/scenes-preview.html`：海港午后主场景与五套不同风景、色彩的窗景照片墙。

## 进入正式页面前的制作清单

1. 按上述结构拆分可替换图层：统一外框 + 用户封面/照片 + HTML 文本，避免插画中的默认海港覆盖所有作品。
2. 根据真实内容准备至少三套不同封面图，并确认在 140 px 宽卡片上仍能看清载体类型。
3. 将首页、唱片册、社区、地图同步换为这套颜色和字级。保留旧版作为对照，统一验收移动端与桌面端。
4. 补齐空状态、加载状态、错误状态和权限提示；这些状态与完整插画同样影响用户是否愿意继续使用。

## 生成提示词归档

本版使用内置 ImageGen，以用户附图作为**画风参考**，分别生成四个透明背景对象。共同约束：明亮的地中海午后、手绘厚涂笔触、海蓝/奶油白/青绿/少量日光金、单一物件、透明背景、无文字和标志。四个主体依次为“露出蓝色黑胶的海边画套”“奶油蓝壳双卷轴磁带”“带蓝色图钉的海边相纸”“蓝漆黄铜投递口的匿名信箱”。
