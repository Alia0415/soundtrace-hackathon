# 界面简化记录 · 2026-10-03

## 方向

让声音和场景成为页面主体：减少说明、重复入口和边框，常用动作直接出现，补充信息按需展开。延续六套手绘资产、Mineradio 原版粒子与播放器效果。

## 本轮调整

- 首页使用完整场景，主要入口为录音；示例试听和声音地图作为轻量入口。最近作品直接进入聆听。
- 录音页突出录音与导入，标题、位置、心情和故事收进可选备注；录音按钮反映录制状态，权限失败给出反馈。
- 收藏间保留横向滑动六个场景，删除重复导航，柜体简化为有厚度和阴影的置物台。有音频的唱片、磁带直接进入聆听，无音频照片保留查看详情。退出聆听后恢复原藏品焦点。
- 统一底部导航线条图标，减轻装饰、标题和按钮的视觉重量；保持触控尺寸和减少动态效果偏好支持。
- 社区缩短输入提示；个人资料按需展开，签到归入个人页，保存与发布仍走原有接口。
- 样式覆盖集中在 `webapp/assets/soundtrace-calm.css`；播放器修改仅在声迹桥接层补充音频读取失败反馈。

## 验证范围

- 检查桌面与 390px 手机宽度下的首页、录音页和收藏间；桌面检查社区、个人页。
- 验证磁带直接进入聆听、详情不再作为必经步骤、退出后焦点恢复；检查展开备注后的页面无横向溢出。
- 检查示例入口、Mineradio 原版播放器和粒子、当前场景的藏品封面。
- 检查页面内联脚本及修改的独立脚本语法，执行 `git diff --check`。

## 当前本地服务边界

8090 端口运行只读预览服务，提供页面和现有 JSON 数据。录音上传、音乐生成、发布及资料保存需要 FastAPI 后端；本轮没有完成这些写入流程的端到端验证。部分已有作品记录引用的音频文件缺失；首页明确标记的示例试听使用仓库内可用 WAV 文件。
