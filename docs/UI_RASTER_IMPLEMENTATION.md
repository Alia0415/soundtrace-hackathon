# 设计图素材接入与分端适配

本次按用户反馈，复用 `webapp/assets/ui-doodle-v1` 中已确认设计图的实际像素。首页、录音、素材库、选择页和社区边景通过 CSS 裁切展示原图区域，不再用代码绘制场景插画。文字、按钮、播放器、选中状态仍是真实 HTML 控件。

## 收藏间

- 桌面：右侧立体书架、左侧照片挂绳，原图背景清理了 UI 和静态藏品后接入。
- 手机：左侧柜子、右侧海景窗；另用手机版背景，不以桌面图缩小替代。
- 唱片、磁带分别放入可横向浏览的层架；照片挂在挂绳区域。
- 三类物件保留点击、键盘激活和拖动；拖动时左侧滑出原设计图中的箱子。
- 场景里的信箱支持点击与键盘打开。
- 六个场景保留滑动切换，窗口视图复用原设计图中的六幅风景。
- Mineradio 引擎、粒子与原版播放器未改动。

## 素材与实现

- `webapp/assets/ui-raster-v2/regions.json`：原图、尺寸和裁切区域。
- `webapp/assets/soundtrace-raster.js`：静态页面的图片展示。
- `studio/src/RasterArt.jsx`：React 图片裁切组件，等比例适配每个显示区域。
- `webapp/assets/soundtrace-raster.css`：桌面与手机的不同排布。
- `webapp/assets/ui-raster-v2/collection-mobile.png`：手机背景。
- `webapp/assets/ui-raster-v2/collection-desktop-clean.png`：桌面背景。
- `webapp/assets/ui-raster-v2/objects.png`：透明物件图集。
- `webapp/assets/ui-raster-v2/prompts.json`：背景整理与物件提取提示词；使用内置 imagegen 编辑模式，未改动原设计图文件。

## 验证

已验证 1440、390、320 像素下的六个路由无页面横向溢出、无浏览器脚本错误。临时数据测试覆盖示例音频上传及复用、主动进入日记、三组情境与其他输入、十种音乐方向、编辑及保存、模拟录音保存、收藏、地图与社区关联。模拟麦克风测试不代表用户真实设备权限状态。

## 2026-10-08 导入入口简化

`/studio` 只提供本地音频上传，`/demo/studio` 另有“演示音频”按钮。两版已移除顶部“我的示例音频”及试听/复用/替换/删除等配套控件。上传后进入当前素材操作，再主动制作音乐日记。录音入口为 `/capture`（演示版为 `/demo/capture`）。

## 2026-10-08 网页声音地图滚动遮挡

桌面声音地图顶部导航和账号入口改为随文档头部滚动，避免头部离开视口后仍悬浮在地图和足迹内容上。正式版、演示版共同生效；手机底部固定导航保留。已验证 1440、1024、800 像素桌面滚动后的定位与地图命中，以及 390 像素手机导航。
