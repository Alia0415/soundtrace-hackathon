# 声迹场景背景 · 第一批

本批资产延续 `VISUAL_SYSTEM.md` 的手绘厚涂、旧木柜、相纸与自然光。布局固定为“落地玻璃窗 + 两侧悬挂照片 + 周边柜体”，以便在不同地点与情绪中切换，同一套页面结构仍保持辨识度。

## 页面接入规则

- 场景图中的照片是画面的一部分。用户真实照片应另建可点击的 DOM 层，置于场景前方；不要把背景里画出来的相纸误认为用户上传内容。
- 桌面端优先完整展示窗与底柜；窄屏优先保留中央窗景，侧柜可能被裁切。此批为横版场景，手机端应另做纵版取景，或用同一素材的局部裁切并单独验证。
- 文字放在独立奶油白半透明承载面上；雨夜和沙漠场景尤其需要检查按钮与正文对比度。
- 六图当前是无损 PNG，适合设计审阅。正式网页发布前应导出响应式尺寸的 WebP/AVIF，并保留本批 PNG 作为母版；不要直接把全部六张原图一次性加载到首页。
- 根据地点、季节或用户主动选择切换主题，默认用海港午后。切换背景不改变内容数据，也不改变唱片、磁带、照片、信箱的操作含义。

本批由内置 ImageGen 根据上一批视觉资产制作，生成时保持统一构图与笔触，并分别指定不同景色、时段和色彩。提示词按用户要求不在本文档列出。

## 对应物件与收藏间

五套非海港场景各有透明四象限物件原图，位于 `webapp/assets/object-sets-v1/`；分离后的页面资产位于 `webapp/assets/object-sets-v2/`。从左上顺时针分别是唱片、磁带、信箱、照片；海港场景沿用 `webapp/assets/visual-v1/` 中的四件独立物件。收藏间在 `webapp/album-room.html`，由 `/album` 路由提供。

照片作为独立可点击图层挂在窗景前方，已有用户照片时叠加真实图片；唱片和磁带按作品与素材接口摆在前景柜架上。柜架由 HTML/CSS 的顶面、正面、侧面和主题色构成，可随六套场景变色。桌面端可拖动物件，触屏可用指针拖动，键盘和触屏也可使用物件上的寄出按钮。开始拖动后，底部信箱从左侧滑出；放进信箱才进入寄出设置。

当前多用户匹配与真正送达仍是演示能力，寄出弹窗会说明这一点；示例物件不会写入寄出记录。

## 四件物品独立裁切

雨夜城市、秋日湖畔、雪山清晨、春日花野、沙漠黄昏五套均有 `webapp/assets/object-sets-v2/{场景}-sheet.png` 透明母图，以及 `{场景}/vinyl.png`、`tape.png`、`photo.png`、`mailbox.png` 四张独立图。每张母图的横纵中线均为空白。裁切时先沿中线分成四个矩形，再依透明像素边界留 20 像素安全边距，避免把相邻物件带进裁图。

秋日、雪山、春日和沙漠四套先使用 `tools/normalize_object_sheet.py` 统一尺寸与象限位置，再用 `tools/split_object_sheet.py` 导出单件；雨夜城市为已验收的样板。`/album` 已全部改用五套独立图，`object-sets-v1/` 保留为原始画稿。
