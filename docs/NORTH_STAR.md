# 声迹 SoundTrace — 北极星（最终目标与细节）

> ⚠️ **2026-09-27 交互重定义（以此为准，覆盖此前的流程描述）**

## 新交互定义（用户原述固化）

**首页**：三个入口按钮——①录音 ②唱片册 ③音乐合成；保留轨迹/地图/打点。
**底部导航（手机端）**：记录 · 收藏间 · 社区 · 我的。
**唱片册**：左侧可隐藏栏——收藏间｜素材库。主画面是**照片墙**（照片钉在墙上，
背后是用户记录/上传的经历图片，点击看留言与当时录音）；墙下**架子摆一排
唱片**（做好的音乐作品）；素材库里未整理素材呈**磁带**形态。
**信箱交换**：照片/唱片/磁带可**拖拽丢进底部信箱**→按双方喜好匿名投递给
另一位用户；信件匿名，可**发起交换联系方式**建立联系；发送时可选择**同步
动态社区**或直发动态；发送者可**授权/禁止**对方使用自己的素材。
**网页端**：上述设计置于顶部，含用户名、头像、注册登录引导、每日签到。

> 一句话：**声迹是把现实世界的声音记忆转化为音乐的 AI 创作小程序。**
> 核心理念：**地点是乐器，记忆是旋律。** AI 不替代创作，而是把用户亲自采集的
> 声音与哼唱变成音乐——最终作品里仍能听见原始环境声，每首作品不可复制。

## 六大支柱（最终形态）

### 1. 记录声音记忆
用户录制/上传环境声，并绑定元数据：
- 采集地点（GPS/POI）、时间、现场照片、一段文字故事、情绪与场景标签
- 每段声音成为"声音地图"上的一个记忆坐标
- 【目标规格】移动端一键录音（小程序录音组件）；素材支持 WAV/M4A/MP3；
  元数据随素材终身携带，进入作品页展示

### 2. AI 智能声音提取
- 自动识别录音中的声源（溪流/鸟鸣/风/脚步/火车/车流/人声…），用户点选保留目标
- 分离 → 降噪 → 切片 → 节拍分析 → 音质优化
- 【技术基座】CLAP 零样本识别（中文自动映射）+ AudioSep 分离（含宽频主导
  减法兜底）+ ClearerVoice/noisereduce 双路降噪 ✅ 已全部上线并实测
- 【缺口】切片/节拍分析尚未接入 DAW（脚步→自动鼓点网格）

### 3. 哼唱生成旋律
- 音高提取 → 音准量化（调性吸附）→ 节奏校正 → 旋律润色 → 和弦/乐器匹配
- **"保留原始哼唱 ↔ AI 自由发挥"滑杆**（产品灵魂交互）
- 【已上线】pyin→调性量化→谐波重合成（8/8 音符准确）；audio2audio 实验证实
  哼唱可直接驱动生成（note-chroma 1.000）→ 待产品化为 UI 选项（T11）
- 【缺口】和弦自动配置、哼唱音色保留（vs 当前合成音色）

### 4. AI 音乐创作（声音明信片）
- 环境声成为乐器：脚步=鼓点、火车=机械节奏、溪流=氛围铺底、鸟鸣=旋律采样、
  风声=空间情绪；用户哼唱=主旋律
- 首版风格：Lo-fi / 氛围空间 / 电影感；产出 30–60 秒立体声明信片
- 【已上线】DAW 排布（拖动/裁剪/循环/散点自动排布/侧链避让/响度归一）、
  ACE-Step 三风格生成、多素材不限数量
- 【缺口】节拍对齐（BPM 网格）、段落结构（前奏-主体-尾声）

### 5. 声音地图
- 作品关联地点与时间；查看自己的声音旅行轨迹；探索城市声音；
  同一地点多作品聚合；按情绪/场景发现；**旅行路线连播成一张专辑**
- 【缺口】整体未开始（依赖小程序端 + 作品元数据）。
  【设计基调】地图全屏 + 底部上滑卡片（参考 Komoot/AllTrails）；
  差异化：轨迹线做"声音浓度渐变"——录过音的路段亮起

### 6. 音乐社区与二次创作
- 素材可公开（用户授权开关）；他人可收藏/采样/加哼唱加歌词；
  不同地点素材组合成新作品；同一段声音的创作挑战与衍生树
- 【缺口】依赖账号体系与后端存储；黑松 MVP 仅做"作品分享卡片"

## 黑客松版边界（当前冲刺）
一个完整闭环：上传环境声 → AI 识别提取 → 录哼唱 → 选风格 → 生成 30–60s
明信片（含散点环境声与哼唱旋律）→ 地点/时间/故事展示 → 保存与分享。
社区/二次创作/路线专辑**不做**，只在产品叙事中呈现。

## 最终愿景
每个用户拥有一张自己的声音地图；无数人的地图连成一张由真实生活构成的
世界音乐地图——每个地点都可以被听见，每段记忆都可以成为旋律。
