## 流程约定

- 录音结束直接保存原声并进入素材库，主动点击制作日记。没有恢复已取消的原声重复问卷。
- 导入页只有上传本地音频；演示版另有演示音频。没有恢复旧“我的示例音频”框。
- 日记仍按天气、心情、状态、自己的话与照片/可选位置、音乐方向依次进入，之后微调。
- 保存更新同一条记忆；收藏、地图、社区及声音交换继续使用真实后端。
- 正式地图、音乐/图片生成及语音识别是否可用，取决于实际服务配置。未配置时显示真实状态，不生成假的成功结果。
- 动态内容（标题、照片、时长、波形、计数）以用户实际数据为准，因此不会固定成设计稿里的示例数值。
