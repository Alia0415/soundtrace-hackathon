今晚提交演示路线（约 3 分钟）

打开部署地址 /demo/studio。演示使用预制音频，数据保存在当前浏览器；不要求麦克风权限、登录或外部模型实时响应。不要把预制样例解说为现场实时 AI 生成。

1. 选“湖边的水声”，点播放原声，听约 3 秒。这里是独立的 16 秒环境声音素材。
2. 点“生成音乐日记”，依次选晴天、平静、散步，填标题“把湖边的下午带回家”和一句故事。
3. 可勾选“记录演示位置（西湖，不获取真实定位）”。这是固定演示点位，不会请求真实 GPS。
4. 选“轻钢琴”。工作台出现两条不同波形：现场原声 16 秒、预制编曲 32 秒。
5. 点播放，切“只听原声”与“只听音乐”，再回到“听完整混音”。也可以选择 Lo-fi / 空灵氛围作对比，三个方向读取不同文件。
6. 收藏并保存。建议先恢复“听完整混音”；当前比例会用于导出。
7. 在成功窗口同步到社区；寄给远方旅人时勾选“接收声音来信”，随后打开信箱，展示明确标注的预设演示回信。
8. 打开声音地图查看新足迹。选择过演示位置的作品显示在地图上；没有选择位置的作品放在未定位列表，仍可播放。
9. 收藏间点击唱片，播放器左上角可切换“现场原声 / 音乐成品”，展示同一条记忆的前后区别。

样例说明
- 六个内置场景各有独立的 demo-raw-*.wav 与 demo-mix-*.wav，不再共用一首唱片，更不再把唱片文件当原声。
- 环境样例由仓库既有水声、鸟鸣、风声素材与程序雨声整理，是演示素材，不宣称是用户实地录制。
- 音乐基底来自此前正式 Mureka 联调成功的纯音乐结果，截取后做钢琴 / 慢拍 / 氛围三个预制编曲；本轮没有追加付费生成请求。
- 内置成品前两秒保留原声，随后音乐渐入，末尾淡出。编辑器将原声与音乐分轨，支持自行调整混音。
- 示例照片与磁带播放原声；唱片播放成品。演示社区帖子播放对应成品。
- 演示 API 写入被限制在浏览器内，不会向正式账号发布动态或给真实用户发送信件。
- 老版本内置样例会自动更新音频引用，保留用户自行制作的演示作品；需要干净演示时，可由演示空间菜单主动重置示例。

音频制作工具：tools/build_demo_audio.py（需要 numpy/scipy，仅制作时使用）。部署只读取已提交的 WAV，不需要额外音频依赖。
