# 記憶之室

沿用原分支五張夢境場景圖，入口現由 React / Vite 載入，互動程式位於 `src/MemoryRoom.jsx`。

## 已完成

- 推門、房間、記憶櫃、記憶池、記憶球五個場景。
- 可點選試聽的瓶子、三瓶托盤、放回及選擇恢復。
- 匯入瀏覽器可解碼的音訊（每段 25 MB / 180 秒以內），以 IndexedDB 保存原始檔。
- 倒入動畫、防止重複倒入、池水漣漪與混音失敗重試。
- 所選素材循環、錯開進場、淡入淡出、音量與峰值控制，輸出 24 秒立體聲 WAV。
- 記憶球命名、收藏最近一個作品、重新開啟恢復，以及 WAV 下載。
- 行動版排版與減少動態效果設定。

## 開發與驗證

`npm ci` 後執行 `npm run dev -- --host 127.0.0.1`。

執行 `npm run build`、`npm run test:sites`、`node --test tests/audio.test.mjs`。

## 邊界

目前是本機聲音拼貼，沒有接入 AI 作曲或 AudioSep。三個內建素材是示例。
私人音訊與收藏保存在目前瀏覽器的目前網站來源，清除網站資料會移除收藏；請下載重要作品。
目前保存最近一顆記憶球，再次收藏會更新該作品。未實作跨裝置同步或完整作品歷史。
